# Lecture

Lecture 是一款只在本机运行的 macOS 英文课堂助手。双击应用后，它会在菜单栏运行，并打开本地网页。

## 功能

- 使用 Mac 麦克风保存完整课堂录音
- 本地 Whisper 实时英文识别，保存可回听时间轴
- Apple 本地英文到简体中文低延迟翻译
- 课程词汇表辅助专业术语识别
- 课后本地远场长录音复核，实时稿与复核稿分别保留
- 可接入 DeepSeek、OpenAI、OpenRouter、本地服务或任意 Chat Completions 兼容模型，校正中文、生成学习总结并做带时间引用的问答
- 课程历史、重点标记、录音跳转和可恢复处理
- 课堂详情可导出带时间轴的 Markdown 学习档案
- 设置页显示录音、历史库与导出文件的本地存储占用
- 默认预设为 DeepSeek V4 Flash；服务地址和模型名可在网页自由修改
- API Key 只需在网页输入一次，由本机安全保存；音频不会上传给聊天模型

## 使用

1. 打开 `/Applications/Lecture.app`。
2. 首次使用时允许麦克风权限。Lecture 的 Whisper 英文识别不依赖云端。
3. 在“课程历史”中新建课程，可加入专业词汇。
4. 在“实时课堂”选择课程并开始。关闭网页不会停止录音；菜单栏的 `L.` 可重新打开。
5. 结束后保留原录音，本地复核英文，并在配置任意兼容 AI 服务后生成校正翻译和总结。总结页会明确显示所选课程与具体哪次课堂，不会自动跳到最近一节。
6. 在课堂详情页点击“导出 Markdown 学习档案”，可保存文字版总结、重点、双语术语表和逐字稿；导出文件不包含录音。

准确度受教授距离、回声、口音和噪声影响。Lecture 不承诺 100% 正确，而是保留原音频、时间轴、可信度与多版本文本，保证可核对。

## 本地英文识别如何提高准确度

- 开始课堂前自动检查本地 Whisper 引擎和英语模型。
- 每门课可选择教授的英语地区，并维护专业术语、人名和缩写词汇表。
- 词汇表会作为 Whisper 的课程提示词，强化专业名词、人名和缩写。
- 约每 2.5 秒更新实时草稿；约每 5 秒确认一段，或在检测到约 0.75 秒停顿时提前自动断句。
- 默认使用约 488 MB 的 Whisper small.en 提升英文课堂准确度；本地 Silero VAD 过滤静音和常见 Whisper 幻觉。
- 停止课堂后再用完整录音和课程词汇复核。安装脚本会校验模型哈希，已有 base.en 会保留作兼容回退。
- 如果完整录音复核失败或明显比实时稿稀疏，Lecture 会自动保留并使用更完整的实时英文，不会让课后页面变成空白。
- 原始录音、实时稿、课后复核稿和中文版本分别保存，聊天模型不会覆盖英文证据，也不会接收音频。

最重要的外部因素仍是收音：尽量把 Mac 放在教授附近，避免键盘敲击与多人重叠讲话。大型教室优先让教授佩戴无线领夹麦；其次是在前排放置指向性 USB 麦克风或手机。外接麦如果仍放在电脑旁、离教授很远，提升会有限。

字幕按时间从上往下追加。人在底部时会自动跟随最新内容；向上阅读旧内容时，草稿和字幕刷新会保留当前阅读位置。

DeepSeek 没有音频多模态能力并不影响这个流程：音频先由本机 Whisper 识别成英文，聊天模型只处理文字。Vision 模型也不等同于音频识别模型，因此无需仅为“能听音频”而更换多模态模型。

Whisper CLI 的稳定 JSON 输出目前不提供可直接对应真实准确率的句级可信度，因此课堂详情以原音、时间轴和实时/复核双版本作为主要复核证据；需要严格验收时，应使用已知对照稿计算词错误率（WER）。
开发或验收时可把人工正确稿和识别稿保存为 UTF-8 文本，再运行 `python3 scripts/measure-wer.py 正确稿.txt 识别稿.txt`。
