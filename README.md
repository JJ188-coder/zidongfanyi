# Lecture

Lecture 是一款只在本机运行的 macOS 英文课堂助手。双击应用后，它会在菜单栏运行，并打开本地网页。

## 功能

- 使用 Mac 麦克风保存完整课堂录音
- 本地 Whisper 实时英文识别，保存可回听时间轴
- Apple 本地英文到简体中文低延迟翻译
- 课程词汇表辅助专业术语识别
- 课后本地远场长录音复核，实时稿与复核稿分别保留
- DeepSeek 校正中文、生成学习总结并做带时间引用的问答
- 课程历史、重点标记、录音跳转和可恢复处理
- 课堂详情可导出带时间轴的 Markdown 学习档案
- 设置页显示录音、历史库与导出文件的本地存储占用
- API Key 仅存放在 macOS 钥匙串；音频不会上传

## 使用

1. 打开 `/Applications/Lecture.app`。
2. 首次使用时允许麦克风权限。Lecture 的 Whisper 英文识别不依赖云端。
3. 在“课程历史”中新建课程，可加入专业词汇。
4. 在“实时课堂”选择课程并开始。关闭网页不会停止录音；菜单栏的 `L.` 可重新打开。
5. 结束后保留原录音，本地复核英文，并在配置 DeepSeek 后生成校正翻译和总结。
6. 在课堂详情页点击“导出 Markdown 学习档案”，可保存文字版总结、重点、双语术语表和逐字稿；导出文件不包含录音。

准确度受教授距离、回声、口音和噪声影响。Lecture 不承诺 100% 正确，而是保留原音频、时间轴、可信度与多版本文本，保证可核对。

## 本地英文识别如何提高准确度

- 开始课堂前自动检查本地 Whisper 引擎和英语模型。
- 每门课可选择教授的英语地区，并维护专业术语、人名和缩写词汇表。
- 词汇表会作为 Whisper 的课程提示词，强化专业名词、人名和缩写。
- 每约 6 秒在本机确认一段英文并持久化；停止时会冲刷最后不足 6 秒的尾段。
- 停止课堂后，Whisper 会使用完整录音和课程词汇在本机重新复核一次。
- 原始录音、实时稿、课后复核稿和中文版本分别保存，DeepSeek 不会覆盖英文证据。

最重要的外部因素仍是收音：尽量把 Mac 放在教授附近，避免键盘敲击与多人重叠讲话；大型教室建议使用指向性 USB 麦克风。

Whisper CLI 的稳定 JSON 输出目前不提供可直接对应真实准确率的句级可信度，因此课堂详情以原音、时间轴和实时/复核双版本作为主要复核证据；需要严格验收时，应使用已知对照稿计算词错误率（WER）。
开发或验收时可把人工正确稿和识别稿保存为 UTF-8 文本，再运行 `python3 scripts/measure-wer.py 正确稿.txt 识别稿.txt`。
